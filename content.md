## Geospatial

I've created [FlatGeobuf](https://github.com/flatgeobuf/flatgeobuf), a binary format for geographic data designed for efficient reading and writing, including spatially indexed access.

I also made [JSTS](https://github.com/bjornharrtell/jsts), a JavaScript port of the JTS geometry library. It provides spatial predicates and operations for processing geometry in web and Node.js applications.

Contributed to [JTS](https://github.com/locationtech/jts), [GeoTools](https://github.com/geotools/geotools), [GeoServer](https://github.com/geoserver/geoserver), [OpenLayers](https://github.com/openlayers/openlayers), [PostGIS](https://github.com/postgis/postgis), and [GDAL](https://github.com/OSGeo/gdal).

## Beyond geospatial

In Rust, I build [seamark](https://github.com/bjornharrtell/seamark), a framework for JSON:API servers, and [rearcut](https://github.com/bjornharrtell/rearcut), a polygon triangulation library. My .NET projects include [PgKeyValueDB](https://github.com/bjornharrtell/PgKeyValueDB) and [PgEFCoreCopy](https://github.com/bjornharrtell/PgEFCoreCopy).

Contributed to [FlatBuffers](https://github.com/google/flatbuffers).
